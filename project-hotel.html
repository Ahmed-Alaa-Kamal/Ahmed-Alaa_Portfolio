Project Overview

A software application designed to solve core hospitality operations, including managing room inventories, handling booking lifecycles, and organizing customer records. The codebase is organized strictly around the Model-View-Controller (MVC) architectural pattern to ensure clean separation between database operations, application logic, and presentation views.

Key Features & Implementation

  • MVC Architectural Pattern: Separated concerns into dedicated Controllers, data-access Models, and modular Views.
  • Relational Database Schema: Engineered a normalized MySQL schema managing relational entities for guests, room categories, booking states, and staff roles.
  • Package & Dependency Management: Configured Composer for handling autoloader mappings and vendor packages cleanly.
  • Data Integrity & CRUD: Implemented structured server-side request routing and parameter handling to ensure accurate transaction records.
